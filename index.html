How it works Training environment

Describe the environment a workshop needs. The pull request adds it to the app creator, and merging it builds one app per interface, each in its own repository, ready to add to the training environment.

1App

Lower case letters, digits and hyphens. It names the repositories and images, and cannot change later.

Shown on the dashboard, with the interface in brackets.

2Interfaces

Each interface becomes its own app and repository, sharing the name, features, data and software.

3HPC features

Emulated inside each session, so learners can practise cluster workflows on the training environment.

NVIDIA cards that nvidia-smi, nvtop, Slurm and PyTorch all see, with real memory limits. There is no physical GPU: everything runs on the CPU, so timings say nothing about GPU performance.

GPUs in each session
Cards on each session's node

A small card makes out-of-memory errors cheap to teach.

A single-node scheduler in the session: sbatch, squeue, scancel, sinfo, sacct, with Slurm's options and output, plus NeSI's own seff and svisit from opt-nesi-bin.

Always on with emulated GPUs, which are requested through Slurm. Their node is gpunode001 in partition gpu.

module avail and module load, in terminals and batch jobs. Each conda package becomes a module rather than being on PATH.

4Data

Baked into the image, and copied into each learner's home directory when a session starts. Files that already exist are never overwritten, so work survives a restart.

No data yet.

5Software

One package per line. JupyterLab, VS Code and the basics (git, Python, curl, vim, nano, rsync, ...) are already there.

Common packages

Versions as name=1.2. Each command is on PATH, or a module with Lmod.

    One-click pull requests with a token

    With a token, this page opens the pull request itself, and can load existing apps to edit. The token stays in this browser and is only sent to GitHub.

    1. Create a fine-grained token: resource owner reannz-training-environment, only the training-environment-app-creator repository, with Contents and Pull requests set to read and write.
    2. Paste it here.
